# Agentic Kernel Engineering

Application of Bayesian optimization (BO) with Gaussian process regression (GPR)
to find the global minimum in the space of possible matrix–intercalant
configurations on a model graphite–lithium structure.

This project is part of the **AI4Science** course at YSDA.
The goal is twofold:

1. **Research goal.** Explore how to encode the local environment of Li atoms in graphite and silicon anodes with SOAP descriptors and statistical pooling into a fixed-length feature vector suitable for BO & GPR, then
   compare kernel choices for the surrogate model.
2. **Meta goal.** Evaluate how much an LLM agent accelerates immersion into a new research topic and the development of a working MVP.

No cluster, DFT, MD, or MLIP calculations are performed. Work is local:
literature analysis, code prototyping, and verification.
