# L2 — Key claims (one sentence each)

Source: `data/papers/shuaib2024_multikernel_amorphous.pdf`

1. A hybrid similarity kernel combining local (SOAP) and long-range (Coulomb matrix) descriptors via an average-kernel approach enables direct comparison of amorphous configurations.
   [verified: p. 1, "We present a hybrid similarity kernel that exemplifies the integration of short- and long-range descriptors via the use of an average kernel approach."]

2. The average SOAP kernel is computed cheaply by retaining the average SOAP fingerprint across all atomic environments in each structure, giving a fixed-length representation regardless of atom count.
   [verified: p. 5, "the computation of K_SOAP is achieved at low cost by retaining the average SOAP fingerprint across all atom environments in both structures."]

3. The hybrid kernel is a weighted sum K_hybrid = (1−δ)·K_SOAP + δ·K_Coulomb, where δ controls the relative weight of local vs long-range descriptors.
   [verified: p. 6, "K_Hybrid(A,B) = (1−δ)×K_SOAP(A,B) + δ×K_Coulomb(A,B)."]

4. The best δ is chosen as the value giving the lowest average standard deviation of energies across clusters, <σ>_E.
   [verified: p. 9, "the best δ value is the one corresponding to the lowest average standard deviation."]

5. Using SOAP alone (δ=0) as a global descriptor is insufficient for classifying disordered systems, producing widely dispersed, overlapping clusters.
   [verified: p. 9, "These results indicate the limitations of using SOAP as a global descriptor for classification of disordered systems."]

6. The active-learning loop grows the training database by a fraction I_perc per iteration until the GAP model meets an energy-convergence threshold E_tol = 2 meV/atom.
   [verified: p. 8, "The energy convergence threshold (E_tol) is user-defined and is set to 2 meV/atom in this work."]

7. Bayesian optimization is used to automatically tune GAP hyperparameters by minimizing test-set energy RMSE.
   [verified: p. 8, "BO is an effective methodology for the automatic optimization of hyperparameters in ML models that are computationally expensive."]

8. Accurate MLIPs with <2 meV/atom RMSE were obtained with only 175 configurations (10–14% of the reference data).
   [verified: p. 1, "Accurate potentials with less than 2 meV/atom root mean square energy error compared to the reference data are obtained. This accuracy is achieved with only 175 configurations."]

9. MLIPs trained on the minimal hybrid-kernel-selected database match those trained on the full dataset and reproduce FPMD/experimental structure factors and PDFs.
   [verified: p. 15, "this minimal sizedatabase approach leads to the same results when a large sizedatabase is used to fit the MLIP."]

10. SOAP-only-selected potentials (MLIP(1)) were unstable at large system sizes, unlike the hybrid-selected MLIP(0).
    [verified: p. 14, "when producing models with 1920 atoms and larger sizes using MLIPA(1), the potential turned out to be unstable."]
