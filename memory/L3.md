# L3 — One-sentence summary

Source: `data/papers/shuaib2024_multikernel_amorphous.pdf`

The paper presents an automated active-learning workflow that clusters amorphous configurations using a hybrid SOAP+Coulomb average similarity kernel (with an optimized mixing weight δ), samples a minimal training database from the clusters, and fits Gaussian approximation potentials whose hyperparameters are tuned by Bayesian optimization, achieving <2 meV/atom accuracy with as few as 175 configurations and stable ~30 000-atom models that match first-principles and experimental data.
